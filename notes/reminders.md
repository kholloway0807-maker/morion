# Reminders & Schedule

The morning briefing reads this file for the "Today's schedule" section.
There's no live calendar integration in this repo, so this file is the source
of truth — jot things here (or ask Claude to add them in any session).

Format: one line per item, prefixed with a date.

## Dated

- _example:_ 2026-06-15 — Invoice due for client X

## Recurring

- _example:_ Every Monday — post Novaly content calendar for the week
